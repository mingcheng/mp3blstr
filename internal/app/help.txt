mp3blstr is a modern re-implementation of the classic mp3blaster

About
=====

  mp3blaster is a classic console audio player written by
  Bram Avontuur:
      https://github.com/stragulus/mp3blaster

  mp3blstr is a modern re-implementation written in pure
  Golang by mingcheng <mingcheng@outlook.com>:
      https://github.com/mingcheng/mp3blstr

  More than two decades ago, as a student, I listened to
  music with mp3blaster every day. Sadly, the original is
  no longer maintained and has slowly faded into history.
  Many thanks to Bram Avontuur and everyone who contributed
  to mp3blaster.

  Now, mp3blstr brings it back: the same screen layout,
  shortcut keys, play logic and playlist files as the
  original, plus modern features - mouse support, true
  colour themes, Nerd Font icons, a YAML configuration
  file, session saving and cancellable background scans.
  It runs on macOS, Windows, Linux and FreeBSD.

Mouse support
=============

  Click          Move the selection bar to a line.
  Double click   Same as ENTER (play a song, open a group
                 or directory, load a playlist).
  Right click    Select/unselect a line (like SPACE).
  Wheel          Scroll through the list.
  Buttons        The CD-player buttons on the right, the
                 shuffle/repeat check boxes, the play mode
                 line, 'Threads', the help bar entries,
                 ( - ) / ( + ) and the mixer ([<] / [>]) can
                 all be clicked. Use the wheel on the mixer
                 to change the volume.
  Progress bar   Click to jump to that position in the song
                 (wide information panel).
  Volume bar     Click to set the volume (wide panel).
  Input line     Click to move the cursor in a popup.
  --no-mouse or ui.mouse: false disables the mouse.

Popups and dialogs
==================

  Text input     ENTER accepts, ESC cancels.
  Confirmation   'y' confirms; 'n', ESC or ENTER cancel.
  Background scan
                 ESC or 'c' (or a click on Cancel) stops it.
                 Music keeps playing while scanning.

Commands specific to Normal Mode
================================

SELECT FILES
  Enter File Mode.

ADD GROUP
  Add a group to the playlist. A group can be thought of as
  an album or a music category. Groups can be nested
  indefinitely.

SET GROUP TITLE
  Change the name of the highlighted group. You will be
  asked to enter a name.

LOAD/ADD PLAYLIST
  Enter File Mode in the playlist directory (PlaylistDir).
  Press ENTER on a playlist (.lst or .m3u) to add its
  contents to the current group.

WRITE PLAYLIST
  Save the complete playlist as an M3U file in the playlist
  directory (by default your Music folder). Groups are kept
  as group-title tags.

CLEAR PLAYLIST
  Remove all entries from the playlist (without asking!).
  Only works when nothing is playing.

REMOVE DUPLICATES
  Remove repeated song paths across all playlist groups,
  keeping the first occurrence. Only works when nothing is
  playing. Press D in Normal Mode.

MOVE FILES AFTER / MOVE FILES BEFORE
  Move the selected songs after (or before) the highlighted
  entry, in the order in which they were selected. Songs
  can't be moved between groups.

SELECT FILE
  Select or unselect the highlighted song. Selected entries
  are shown in bold.

DELETE
  Remove the highlighted entry from the playlist.

ENTER
  On a song: play it immediately. When a playlist was
  playing it continues after this song.
  On a group: enter the group. The special group '[..]'
  takes you back to the parent group.

TOGGLE REPEAT
  Start again from the beginning when the playlist ends.
  Available in all modes.

TOGGLE GROUPSHUFFLE
  Play the songs of the current group in random order.
  Available in all modes.

TOGGLE PLAY MODE
  Choose between playing the current group only, the
  current group including all its sub groups, or all songs
  of all groups in random order. Not possible while
  playing.

Commands specific to File Mode
==============================

ADD FILES TO LIST
  Leave File Mode and add all selected files to the
  current group. Files can be selected in several
  directories before adding them.

INVERT SELECTION
  Select all unselected files and vice versa.

RECURS. SELECT ALL
  Add all audio files in this directory and in all its sub
  directories to the current group. Scanning runs in the
  background with a progress dialog (current directory,
  files and folders found, elapsed time); press ESC or 'c'
  (or click Cancel) to stop it without adding anything.

ENTER NEW PATH
  Type the name of a directory to go to.

ADD DIRS AS GROUPS
  Every sub directory (recursively) containing audio files
  becomes a group in the playlist. Like RECURS. SELECT ALL
  this shows a progress dialog and can be cancelled.

ADD URL (SHOUTCAST)
  Add an http:// stream (Shoutcast/Icecast) to the files
  that will be added to the playlist.

TOGGLE FILE SORT
  Cycle through the 7 sort modes: alphabetical (case
  insensitive / sensitive), modification date (newest /
  oldest first), size (smallest / biggest first) and
  unsorted. Directories are always listed first.

GO UP ONE DIR
  Go to the parent directory.

SELECT FILE
  Select or unselect the highlighted file.

RENAME FILE / DELETE FILE
  Rename the highlighted file or delete it (after asking for
  confirmation).

ENTER
  Enter a directory, load a playlist or play a song.

Commands available in all modes
===============================

PLAY SONG          Start the playlist, or pause/resume.
STOP SONG          Stop playing and reset the playlist.
PREVIOUS/NEXT SONG Go back in the play history / skip.
REWIND/FORWARD     Skip SkipLength seconds (default 10).
SKIP TO END SONG   Jump to the last seconds of the song.
PREVIOUS/NEXT GROUP
                   Skip the rest of the group being played.
TOGGLE FADE OUT    Fade out the end of known-length songs (V).
                   The length is set by playback.fade_seconds
                   in the config file (default 5).
START SEARCH       Type the beginning of a name to jump to
                   it. The search ends after 2 seconds of
                   inactivity or with ENTER / ESC.
TOGGLE FILE DISPLAY
                   Show full paths, file names or ID3 tags
                   (playlist), or names, sizes or ID3 tags
                   (file manager).
SELECT SOME ITEMS  Select entries matching a pattern
                   (shell wildcards, or regular expressions
                   with SelectItems.SearchRegex = yes).
UNSELECT ALL       Clear the selection.
CHANGE #THREADS    Size of the read-ahead buffer used for
                   the next song (0 disables it).
TOGGLE MIXER DEVICE
                   Switch between Volume and Balance.
MIXERVOLUME DOWN/UP
                   Change the current mixer device.
                   Keys that are not bound to a command also
                   control the mixer: 'k' / 'j' switch the
                   device, 'h' / 'l' change it and '0' sets
                   it to zero.
PAN WINDOW LEFT/RIGHT
                   Scroll long names horizontally.
TOGGLE LIST WRAP   Wrap around at the ends of lists.
SWITCH THEME       Cycle through the colour themes (classic,
                   modern) at run time.
TOGGLE NERD FONT   Switch between plain symbols and Nerd
                   Font icons at run time.
START/END OF LIST, PREVIOUS/NEXT PAGE, MOVE SCROLLBAR
                   Navigate in the main window.
REFRESH SCREEN     Redraw everything.
SCROLL HELPTEXT    '-' / '+' page through the key help bar
                   at the top of the screen.
SHOW HELP          Show (or leave) this screen.
QUIT MP3BLSTR   Leave the program. Changed settings, the
                   playlist and the current song and its
                   position are saved for the next start
                   (unless state.save is false). Asks
                   for confirmation first unless
                   ui.confirm_quit is false.
